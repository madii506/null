# null

Most coins return null.

A launchpad on PumpSwap where a coin lives only while it trades. 72 hours of silence on its pool and it returns null.

Everything on the site is read live from Solana (names and prices from DexScreener). The server builds transactions; your wallet signs them.

Env: `NULL_STUDIO` (studio public key, enables launches), `NULL_CA`, `NULL_X`, `RPC_URL` (optional).
